04 · 工作流程

录制流程

从订阅直播间到回放文件，各环节由后端自动完成。

01

订阅房间

填入直播间号即可完成订阅，后端会持续检查开播状态。

02

开播即录

检测到开播后自动开始录制，并可通过 Web Push / SSE 推送开播通知。

03

缓冲写盘

采用大块缓冲与序列化写入；断流时自动重连，恢复后另起新文件，不覆盖已录制的内容。

04

自动分段

PK 连线或分辨率变更时自动切分文件，减少花屏与文件损坏。

05

互动存档

弹幕、礼物、醒目留言保存为与视频同名的文件，各分段互相对应。

06

转码回放

可使用本地 FFmpeg 或 CloudConvert 转换为 MP4；内置播放器支持弹幕滚动与礼物特效回放。

05 · 低配优化

低配设备优化

针对低配硬件与长时间运行场景的默认策略，均可在配置中调整。

DROP_FILE_PAGE_CACHE=true

文件页缓存释放

一段录制完成或转码成功后释放整份文件页缓存，避免容器监控内存持续上涨。默认开启。

microSD 友好

microSD 写入优化

采用大块缓冲与序列化写入，并跳过过短直播的写盘，减少存储卡写入次数。

断流恢复策略

断流恢复

FLV 时间戳修复与断流自动重连；恢复后以新时间戳另起文件，不覆盖断流前已录制的内容。

HDD / NAS 调优

HDD / NAS 调优

文档提供针对机械硬盘与高码率场景的 IO 调优参数，可按需调整。

06 · 监控

运行指标监控
