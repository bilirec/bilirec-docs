## 浏览文件

```http
GET /files/browse/*
```

| 参数 | 说明 | 默认值 |
| ---- | ---- | ------ |
| `offset` | 分页偏移量 | `0` |
| `limit` | 每页最大条数（0=不限制，最大 200） | `0` |
| `search` | 按文件名搜索（大小写不敏感） | (不过滤) |
| `only_media` | 为 `true` 时只列出目录与录制媒体文件（mp4、m4a、ts、fmp4、flv） | `false` |
| `start` | 按文件名中的录制时间过滤**文件**（下限，格式 `20060102_150405`，闭区间） | (不过滤) |
| `end` | 按文件名中的录制时间过滤**文件**（上限，格式 `20060102_150405`，闭区间） | (不过滤) |

列表默认排序：**子目录**按最后修改时间从新到旧；**文件**按文件名末尾的录制时间戳从新到旧（无法解析时间戳的文件排在最后）。目录不受 `start` / `end` 影响。分页在过滤与排序之后进行。

```json
{
  "total": 42,
  "items": [
    { "name": "title.flv", "is_dir": false, "path": "room123/title.flv", "size": 1048576 }
  ]
}
```

## 下载文件

```http
GET /files/download/{path}?presigned={token}
```

需要携带有效的预签名 token（见下方「预签名下载」，`purpose` 使用 `download` 或省略）。token 与请求路径绑定，路径不符返回 `403`，过期返回 `403`，缺失返回 `401`。

直接返回存储的文件。

若要将源文件（FLV/TS/fMP4）自动转为 MP4 或 M4A，可启用 `CONVERT_TO_MP4`。录制结束后可转换文件会被加入转换队列：

- 同时设置 `CLOUDCONVERT_API_KEY` 且文件大小 `>= CLOUDCONVERT_THRESHOLD`（默认 1 GB）时，优先走 CloudConvert
- 否则走本地 FFmpeg 后台任务
- 转换任务可通过 `GET /convert/tasks` 查询

## 预签名下载

```http
POST /files/presigned/{path}?ttl=<seconds>&purpose=<purpose>
```

需要 JWT 认证。`ttl` 默认 3600 秒。`purpose` 决定返回的 URL 指向哪条路由：

- `download`（默认）：返回 `/files/download/{path}?presigned=<token>`，以附件形式下载
- `playback`：返回 `/files/playback/{path}?presigned=<token>`，用于浏览器内联播放
- `share`：返回同 `download`，但每次都签发全新链接，适合分享场景

`download` 与 `playback` 会复用 URL：同一文件、同一用途在到期前重复请求时，返回同一条 URL，便于 CDN 按稳定网址缓存；此时 `expires_in` 是该 URL 的剩余有效秒数。剩余不足 5 分钟时才会重新签发新 URL。`share` 则不受影响，总是返回新链接。

返回的 URL 无需 cookie 即可访问，适合交给 CDN、外部播放器或下载工具重放。token 与文件路径绑定并带过期时间，过期后失效；正在录制的文件无法生成。

## 批量删除

```http
DELETE /files/batch
Content-Type: application/json

["room123/20250101.flv", "room456/20250102.flv"]
```

```http
DELETE /files/{path}
```

## 在线播放

```http
GET /files/playback/{path}?presigned={token}
```

需要携带有效的预签名 token（`purpose` 使用 `playback`）。返回 MP4 或 M4A 媒体流，浏览器可直接播放。支持 Range 请求（快进/快退）。

- 支持 MP4 与 M4A
- 无法播放进行中的录制文件（正在写入的分段请用 [录制中预览](/zh-cn/api/preview/)，仅管理员）
- token 过期后返回 `403`，播放器应在过期前重新调用预签名接口换取新 URL

```html
<video controls width="100%">
  <source src="/files/playback/username-roomID/20250101.mp4" type="video/mp4">
</video>
```

## 获取视频对应的弹幕文件

```http
GET /files/danmaku/{path}
```

`path` 传入视频文件路径，服务会查找与视频同名的弹幕文件，并优先返回 `.jsonl`，找不到时再尝试 `.xml`：

```bash
curl "http://127.0.0.1:8080/files/danmaku/username-roomID/20250101.mp4"
```

返回内容类型为 `application/x-ndjson` 或 `application/xml`。当前视频分段仍在录制时返回 `400`；没有对应弹幕文件时返回 `404`。
