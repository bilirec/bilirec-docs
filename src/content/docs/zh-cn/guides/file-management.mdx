bilirec 将录制文件保存在 `OUTPUT_DIR`（默认 `records`）目录下，可通过 Web 界面或 REST API 管理。

## 浏览文件

在 Web 界面的文件管理页面浏览录制目录，支持按文件名搜索与分页。录制弹幕后，与视频同名的弹幕文件也会显示在文件列表中。

API：

```bash
curl "http://127.0.0.1:8080/files/browse/?offset=0&limit=50&search=title"
```

## 弹幕文件

开启弹幕录制后，每个视频文件旁边可能会有同名的 `.jsonl` 或 `.xml` 文件。它们保存普通弹幕、醒目留言、礼物和舰长等互动记录，不是视频文件，不能直接用视频播放器打开。

使用 bilirec-web 回放时，宜选 `.jsonl`，播放器方能还原滚动弹幕与礼物特效。`.xml` 则按 [弹幕 XML 的后续使用](/zh-cn/guides/danmaku-xml/) 接入录播姬生态里的 XML 工具；Web 播放器不为 XML 叠这些效果。

## 下载文件

```bash
curl -O "http://127.0.0.1:8080/files/download/room123/title.flv"
```

## 在线回放

已转换为 MP4 的文件可以在 Web 界面的内置播放器中回放，也可以通过 API 直接获取视频流：

```bash
curl "http://127.0.0.1:8080/files/playback/username-roomID/20250101.mp4"
```

</Aside>

## 预签名下载

需要认证，创建临时下载链接：

```bash
curl -X POST "http://127.0.0.1:8080/files/presigned/room123/title.mp4?ttl=3600" \
  -b cookies.txt
```

## 分享链接

在 [Web 管理界面](/zh-cn/guides/web-ui/) 的录制文件列表中，可为单个文件生成带有效期的分享链接（复制到剪贴板后发给他人）。接口与上文的预签名下载相同：对方在有效期内访问链接即可下载，无需登录。

<Aside type="note">
**需要对外可访问的后端。** 他人打开链接时会向你的 bilirec 后端发起下载请求。若服务只在本机或局域网内、未做内网穿透或反向代理，公网上的用户无法拉取文件。请先将 API 暴露到外网（例如 [FRP](/zh-cn/guides/frp/)），再配置可从公网访问的完整基址 `PUBLIC_BASE_URL`（见 [服务器与网络](/zh-cn/configuration/server-network/)）。`PUBLIC_BASE_URL` 为空或无效时，后端会回退为相对路径，对方拿到的链接通常无法直接使用。

**bilirec-mobile 场景。** 原生 App 没有单独的「分享」入口，须在「打开录制管理程序」进入 Web/PWA 后操作。手机常见部署下后端仅监听本机 `127.0.0.1`，且 App 设置页未提供 `PUBLIC_BASE_URL` 开关，一般**无法**向他人提供可用的外链；若确有需要，需自行解决公网可达性，并在开发者选项的环境变量中设置 `PUBLIC_BASE_URL`。
</Aside>

## 批量删除

```bash
curl -X DELETE http://127.0.0.1:8080/files/batch \
  -H "Content-Type: application/json" \
  -d '["room123/20250101.flv","room456/20250102.flv"]'
```

## MP4 转换

启用 `CONVERT_TO_MP4=true` 后，录制完成的 FLV/TS/fMP4 文件会自动加入转换队列。大文件（≥ `CLOUDCONVERT_THRESHOLD`，默认 1 GB）优先使用 CloudConvert 云端转换。

转换任务状态查询见 [转换任务 API](/zh-cn/api/convert/)，配置见 [转换配置](/zh-cn/configuration/conversion/)。

完整 API 参考见 [文件管理 API](/zh-cn/api/files/)。
