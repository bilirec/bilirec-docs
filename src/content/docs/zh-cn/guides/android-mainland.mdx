大陆版国产手机系统（华为 / 鸿蒙、OPPO / realme / OnePlus 的 ColorOS、小米 / Redmi 的 HyperOS、vivo / iQOO 的 OriginOS 等）对后台应用的管理比一般 Android 更严格。若未完成适配设置，Bilirec 在后台时可能出现：

- 网络请求被延迟或中断，导致开播检测、录制拉流超时；
- 前台服务的定时检查（约每 15 秒一次）被系统挂起，通知栏状态不再更新；
- 锁屏、切到其他 App，或从多任务界面划掉卡片后，服务被系统清理；
- Web 管理页出现「**网络异常，正在尝试重新连接...**」——后端被杀、后台联网被限制，或浏览器拦住了本机访问时都会触发；恢复后会短暂显示「网络已恢复」。

<Aside type="note">
本文针对上述**大陆国产系统**。其他品牌（如 Pixel、三星国际版等）通常只需按 [Android App](/zh-cn/guides/android/) 中的电池优化提示操作即可。

可用 App 内的 **检查系统服务连接** 区分：本机接口无响应 → 优先查后台；本机接口正常而管理页仍提示网络异常 → 优先查浏览器是否允许本地网络访问，详见 [常见问题 · 网络异常提示](/zh-cn/guides/faq/#页面一直提示网络异常正在尝试重新连接)。
</Aside>

## 划掉多任务卡片可能会终止后台服务

即使已在 App 内关闭电池优化，在多数大陆国产系统上，从多任务界面**手动上划划掉卡片**，仍属于最高优先级的「用户主动清理」——系统通常会终止该应用的后台进程。

关闭电池优化只能减少系统在卡片**仍留存**时的自动清理，不能避免你主动划掉卡片造成的终止。服务被终止后，Web 管理页通常会提示「网络异常，正在尝试重新连接...」。若希望 Bilirec 在清理多任务后仍保持运行，通常需要**锁定多任务卡片**（各品牌操作见下方对应标签页）。

## 如何设置

建议先完成 Bilirec App 内的**电池优化豁免**，再切换到你手机对应的系统标签页，按顺序**逐步**调整。

<Aside type="tip">
**不必一次做完所有步骤。** 每完成一步，先测试 Bilirec 是否已恢复正常；若问题已解决，**即可停止，无需继续往下做**。这样可以在解决问题的同时，尽量减少对手机省电策略的影响。
</Aside>

<Tabs>
<TabItem label="华为 / 鸿蒙">

### 第一步：关闭「应用自动管理」

主要解决：App 切到后台或重启后服务无法自启、被系统清理。

若已在 Bilirec App 内开启 **开机自动恢复服务**，此处 **允许自启动** 仍是必要条件：App 开关只决定收到开机广播后要不要恢复前台服务，系统若禁止自启动，则开机广播可能根本到不了 App。

1. 打开手机 **设置**，点击 **电池**。
2. 点击 **应用启动管理**。
3. 在列表中找到 **Bilirec**，关闭其右侧的 **自动管理** 开关。
4. 在弹出的手动管理窗口中，**同时勾选** 以下三项：
   - **允许自启动**
   - **允许关联启动**
   - **允许后台活动**
5. 点击 **确定** 保存。

完成后请测试 Bilirec。若后台运行已正常，无需继续下一步。

### 第二步：加入电池优化白名单

主要解决：系统省电策略仍限制 Bilirec 后台活动。

1. 打开手机 **设置**，在顶部搜索栏输入 **电池优化** 并进入。
2. 点击顶部的下拉菜单，将 **不允许** 切换为 **所有应用**。
3. 在列表中找到 **Bilirec**，将其设为 **不允许**（即：不允许系统对本应用进行省电优化）。

<Aside type="tip">
不同系统版本的文案可能略有差异。关键是让 Bilirec **不受电池优化**，与 App 内弹窗提示的目标一致。
</Aside>

完成后请测试 Bilirec。若问题已解决，无需继续下一步。

### 第三步：休眠时保持网络连接

主要解决：锁屏或手机休眠后网络被切断，导致通讯中断或超时。

1. 打开手机 **设置**，点击 **电池**。
2. 点击 **更多电池设置**。
3. 找到 **休眠时始终保持网络连接**（部分版本显示为 **休眠时保持网络连接**），将其 **开启**。

完成后请测试 Bilirec（建议锁屏等待几分钟后再观察）。若问题已解决，无需继续下一步。

### 第四步：在多任务界面锁定应用

主要解决：从多任务列表一键清理时 Bilirec 被连带杀掉。

1. 从屏幕底部向上滑动并停顿，进入 **多任务管理界面**。
2. 找到 Bilirec 的卡片，用手指按住卡片并 **向下滑动**。
3. 当卡片右上角出现 **小锁头** 图标时，表示后台锁定成功。

### 使用移动数据时的额外说明

若在外出时使用 **移动数据**（5G / 4G）仍遇到连接卡顿、请求超时，可能是华为在使用移动数据时对后台进程施加了更严格的限制。可暂时连接 Wi‑Fi 或热点；在 Wi‑Fi 下限制通常会明显放宽。

若前几步已解决问题，其余步骤可不做；若仍有超时，再按顺序尝试后续步骤，或暂时改用 Wi‑Fi。

</TabItem>
<TabItem label="OPPO / ColorOS">

适用于大陆版 **OPPO**、**realme**、**OnePlus**（ColorOS 系统）。

### 第一步：关闭「应用自动管理」

主要解决：App 切到后台或重启后服务无法自启、被系统清理。

1. 打开手机 **设置**，点击 **应用**。
2. 点击 **应用启动管理**。
3. 找到 **Bilirec**，改为 **手动管理**。
4. 勾选 **允许自启动** 和 **允许后台活动**。

完成后请测试 Bilirec。若后台运行已正常，无需继续下一步。

### 第二步：加入电池优化白名单

主要解决：系统省电策略仍限制 Bilirec 后台活动。

1. 打开手机 **设置**，点击 **电池**。
2. 点击 **更多设置**。
3. 点击 **应用耗电管理**。
4. 找到 **Bilirec**，将其设为 **允许完全后台行为**。

<Aside type="tip">
不同系统版本的文案可能略有差异。关键是让 Bilirec **不受省电限制**，与 App 内弹窗提示的目标一致。
</Aside>

完成后请测试 Bilirec。若问题已解决，无需继续下一步。

### 第三步：关闭休眠时的系统自动清理

主要解决：夜间或熄屏后系统强制清理后台，导致通讯中断或服务被终止。

1. 打开手机 **设置**，点击 **电池**。
2. 点击 **更多设置**。
3. 关闭 **睡眠模式优化** 或 **夜间超长续航**（视系统版本显示项而定）。

完成后请测试 Bilirec（建议锁屏等待几分钟后再观察）。若问题已解决，无需继续下一步。

### 第四步：在多任务界面锁定应用

主要解决：从多任务列表划掉卡片时 Bilirec 被立刻终止。

1. 从屏幕底部向上滑动并停顿，进入 **多任务管理界面**。
2. 找到 Bilirec 的卡片，点击卡片右上角的 **⋮**，或 **长按** 卡片。
3. 选择 **锁定**。锁定后，即使点击「全清除」或手动上划，该卡片也会留在后台不被关闭。

</TabItem>
<TabItem label="小米 / HyperOS">

适用于大陆版 **小米**、**Redmi**（HyperOS / 澎湃OS；部分机型菜单仍沿用 MIUI 名称）。

### 第一步：允许自启动

主要解决：App 切到后台或重启后服务无法自启、被系统清理。

小米默认不允许应用自启动；需要后台常驻时，由用户在系统里单独放行。若已在 Bilirec App 内开启 **开机自动恢复服务**，此处 **允许自启动** 仍是必要条件：App 开关只决定收到开机广播后要不要恢复前台服务，系统若禁止自启动，则开机广播可能根本到不了 App。

1. 打开手机 **设置**，点击 **应用设置** 或 **应用**（视系统版本而定）。
2. 点击 **应用管理**（部分版本为 **管理应用**），找到 **Bilirec**。
3. 打开 **自启动** 开关。

若应用详情页没有自启动开关，可改走列表入口：

- **设置** → **应用设置** → **授权管理** → **自启动管理**，打开 Bilirec；或
- 打开 **手机管家** → **应用管理** → **自启动**，打开 Bilirec。

完成后请测试 Bilirec。若后台运行已正常，无需继续下一步。

### 第二步：将省电策略设为「无限制」

主要解决：系统省电策略仍限制 Bilirec 后台活动。

**方法一（多数 HyperOS / MIUI 版本）：**

1. 打开手机 **设置** → **应用设置**（或 **应用**）→ **应用管理**，找到 **Bilirec**。也可在桌面 **长按** Bilirec 图标，选择 **应用信息**。
2. 点击 **省电策略**（部分版本显示为 **省电**）。
3. 选择 **无限制**。

**方法二（部分 HyperOS 2 机型，例如从「省电与电池」进入）：**

1. 打开手机 **设置**，点击 **省电与电池**（部分版本为 **电池**）。
2. 在应用列表中找到 **Bilirec**。
3. 将其设为 **无限制**。

<Aside type="tip">
不同系统版本的文案可能略有差异。关键是让 Bilirec **不受省电限制**，与 App 内弹窗提示的目标一致。若已开启系统 **省电模式**，后台限制通常会更严，可先关闭后再测。
</Aside>

完成后请测试 Bilirec。若问题已解决，无需继续下一步。

### 第三步：在多任务界面锁定应用

主要解决：从多任务列表划掉卡片或一键清理时 Bilirec 被立刻终止。

1. 从屏幕底部向上滑动并停顿，进入 **多任务管理界面**。
2. 找到 Bilirec 的卡片，**长按** 卡片，点击出现的 **锁头** 图标。
3. 部分版本也可 **向下滑动** 卡片，右上角出现锁头即表示锁定成功。

锁定后，请避免再手动上划划掉该卡片；划掉后服务通常会被终止。

</TabItem>
<TabItem label="vivo / OriginOS">

适用于大陆版 **vivo**、**iQOO**（OriginOS；部分机型菜单仍显示「后台高耗电」而非「后台耗电管理」）。

### 第一步：允许自启动

主要解决：App 切到后台或重启后服务无法自启、被系统清理。

若已在 Bilirec App 内开启 **开机自动恢复服务**，此处 **允许自启动** 仍是必要条件：App 开关只决定收到开机广播后要不要恢复前台服务，系统若禁止自启动，则开机广播可能根本到不了 App。

1. 打开手机 **设置**，点击 **应用与权限**（部分版本为 **应用**）。
2. 点击 **应用管理**，找到 **Bilirec**。
3. 进入 **权限**（部分版本需再点 **所有权限**）。
4. 打开 **自启动** 开关。部分版本还可同时打开 **关联启动**。

若在应用详情里找不到该项，可在设置搜索栏输入 **自启动**，进入列表后打开 Bilirec。

完成后请测试 Bilirec。若后台运行已正常，无需继续下一步。

### 第二步：允许后台高耗电

主要解决：系统按耗电策略冻结或限制 Bilirec 后台活动。

1. 打开手机 **设置**，点击 **电池**。
2. 点击 **后台耗电管理**（部分版本显示为 **后台高耗电**）。也可在设置顶部搜索这两个词直接进入。
3. 找到 **Bilirec**，选择 **允许后台高耗电**（部分版本为打开对应开关，或选择 **不限制后台耗电**）。

<Aside type="tip">
不同系统版本的文案可能略有差异。关键是让 Bilirec **允许在后台继续运行**，与 App 内弹窗提示的目标一致。若当前处于 **省电**、**超级省电** 或 **睡眠模式**，后台限制通常会更严，可先改回 **正常模式** 后再测。
</Aside>

完成后请测试 Bilirec。若问题已解决，无需继续下一步。

### 第三步：在多任务界面锁定应用

主要解决：从多任务列表划掉卡片或一键清理时 Bilirec 被立刻终止。

1. 从屏幕底部向上滑动并停顿，进入 **多任务管理界面**。
2. 找到 Bilirec 的卡片，**向下滑动**，或点击卡片上的 **箭头**／菜单。
3. 选择 **锁定**。锁定后，即使清理其他后台，该卡片也会留着不被关闭。

</TabItem>

若关屏闲置较久后出现**录制断断续续**（而非请求超时），可尝试 App 设置中的 **激进防休眠模式**——该选项用于对抗关屏后的系统休眠，与移动网络超时无关。详见 [Android App](/zh-cn/guides/android/#服务启动前设置)。
