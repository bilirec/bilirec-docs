本页按**目标**串起步骤：成片留在你的机器上，访客通过 Web **带弹幕回放**或下载。需要配置管理员与只读账号，并把 API 安全地暴露到公网。

## 适合谁

- 想给粉丝或朋友提供**在线看录播 / 下文件**，而不是只自己看
- 愿意配置**管理员 + 只读访客**账号，并在公网暴露 API 时设密码

其他场景指南：[自用录像库](/zh-cn/guides/personal-archive/)、[全自动挂机上传](/zh-cn/guides/auto-upload/)。

## 步骤清单

<Steps>

1. [安装](/zh-cn/guides/installation/)并[启动](/zh-cn/guides/quick-start/) bilirec，完成 B 站登录。
2. 设置**管理员** `USERNAME` / `PASSWORD`；公网暴露后未设置时 API 完全公开，见 [认证与安全](/zh-cn/configuration/auth-security/)。
3. 设置**只读访客** `VIEWER_USERNAME` / `VIEWER_PASSWORD`：访客可浏览、回放、下载，不能改订阅或开停录。
4. 在 Web「订阅管理」为房间开启**自动录制**，见 [录制直播间](/zh-cn/guides/recording/)。
5. 保持 **`DANMAKU_OUTPUT_FORMAT=jsonl`**，与 bilirec-web 弹幕回放配套，见 [弹幕录制](/zh-cn/configuration/danmaku/) 与 [Web 界面 · 录制与回放](/zh-cn/guides/web-ui/#录制与回放)。
6. 开启 **`CONVERT_TO_MP4=true`**，录制结束后生成 MP4，访客才能在浏览器里稳定回放，见 [转换配置](/zh-cn/configuration/conversion/)。
7. 按需调整 `MIN_DISK_SPACE_BYTES`；某房间可在订阅里开启「空间不足时删除最旧文件」，见 [录制配置 · 磁盘空间](/zh-cn/configuration/recording/#磁盘空间)。
8. 设置 **`PUBLIC_BASE_URL`** 为访客实际访问后端的 HTTPS 基址（含 `https://`），用于分享与预签名下载，见 [服务器与网络](/zh-cn/configuration/server-network/) 与 [文件管理 · 分享链接](/zh-cn/guides/file-management/#分享链接)。
9. 用 [FRP](/zh-cn/guides/frp/) 或自建反代把服务暴露到公网；若用官方 PWA 管理，建议 `PRODUCTION_MODE=true` 与 `FRONTEND_URL=https://app.bilirec.org`，见 [认证与安全 · 生产模式](/zh-cn/configuration/auth-security/#何时需要生产模式)。

</Steps>

<Aside type="caution">

- 公网暴露后务必设置管理员密码。
- 只读账号不能防止分享链接被转发。
- 预签名分享可设有效期（默认 1 小时，可改 `ttl`），见 [文件管理 · 分享链接](/zh-cn/guides/file-management/#分享链接)。

</Aside>

## 配置示例

以下片段可合并进 `.env`（路径、密码请自行替换）：

```bash
OUTPUT_DIR=/path/to/records

USERNAME=admin
PASSWORD=请改为强密码
VIEWER_USERNAME=guest
VIEWER_PASSWORD=请改为强密码
JWT_SECRET=请改为随机长字符串

DANMAKU_OUTPUT_FORMAT=jsonl
CONVERT_TO_MP4=true

MIN_DISK_SPACE_BYTES=5368709120

PRODUCTION_MODE=true
FRONTEND_URL=https://app.bilirec.org
PUBLIC_BASE_URL=https://你的公网后端地址

# FRP_ENABLED=true 等见远程访问（FRP）；不用官方 FRP 时可不设并自建反代
# TRUSTED_PROXIES=反代或 FRP 出口 IP，逗号分隔；见服务器与网络
# delete_oldest_on_low_disk 在 Web 订阅或房间 API 按房间设置，见录制配置 · 磁盘空间
```

## 录完文件在哪？

成片在 **`OUTPUT_DIR`**（默认 `records`）下的 `{主播名}-{房间号}/`；访客在 Web 里看到的即此目录。浏览、分享与在线回放见 [文件管理](/zh-cn/guides/file-management/)。
