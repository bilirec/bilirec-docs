---
title: 用 AI 查文档
description: 用站内问文档、自己的 AI，或文档全文来查找配置与排错说明
---

查配置或排错时，除了翻目录和 [常见问题](/zh-cn/guides/faq/)，还可以让 AI 按本站文档查找。三种方式可以一起用：人还在网页上时用右下角提问；已经在用自己的 AI 时把文档接进去；额度用完或不想配置时，把文档全文交给任意聊天工具。

AI 的回答方便缩小范围。改设置或处理故障时，仍建议对照原文和日志。

## 站内问文档

本站任意页面右下角有「问文档」。用白话描述你看到的现象即可，例如启动报错、回放弹幕变少。回答依据本站文档，每天有使用额度。额度用尽或暂时繁忙时，可改用下面两种方式。

## 接到自己的 AI

如果你已经在用支持 MCP（一种让 AI 读取外部资料的接入方式）的工具，把文档加进去后，就可以直接问安装、配置和排错问题，不必自己复制网页。

地址：

```
https://llm.bilirec.org/mcp
```

在工具的 MCP 或远程服务器设置里填入上述地址。各家界面不同，以工具自己的说明为准。配置文件常见写法：

```json
{
  "mcpServers": {
    "bilirec-docs": {
      "url": "https://llm.bilirec.org/mcp"
    }
  }
}
```

## 把文档全文交给 AI

不想配置 MCP 时，可以把下面的网址发给任意聊天工具，让它先读再回答。这不占用站内「问文档」的额度。

| 文件 | 适合 |
|------|------|
| [`llms.txt`](https://www.bilirec.org/llms.txt) | 只要目录和摘要 |
| [`llms-small.txt`](https://www.bilirec.org/llms-small.txt) | 比目录多一些、比全文短 |
| [`llms-full.txt`](https://www.bilirec.org/llms-full.txt) | 需要细查配置时用完整正文 |

内容和网页上的文档相同。若刚更新过说明，请以网页为准。

## 怎么选

| 你现在的情况 | 更合适的方式 |
|--------------|--------------|
| 正在看文档，只想随口问一句 | 右下角「问文档」 |
| 已经在用自己的 AI，希望它能查本站说明 | 填入上面的地址 |
| 任意聊天工具，或不想额外设置 | 把 `llms.txt` 或 `llms-full.txt` 的网址交给它 |

仍建议先看 [常见问题](/zh-cn/guides/faq/) 是否已有对应条目，再用 AI 缩小范围，最后回到具体配置页确认默认值和注意事项。
