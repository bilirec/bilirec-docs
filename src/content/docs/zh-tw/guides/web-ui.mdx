bilirec 的 Web 管理介面由 [bilirec-web](https://github.com/bilirec/bilirec-web) 提供，線上地址為 [app.bilirec.org](https://app.bilirec.org/)。它是一個通用前端，可連接任何 bilirec 後端實例。

## 功能概覽

| 功能 | 說明 |
|------|------|
| 錄製管理 | 手動開始/停止錄製，查看錄製中 / 恢復中 / 空閒等狀態與統計 |
| 錄製中預覽 | 管理員在錄製進行時打開實時畫面與彈幕（FLV / TS / fMP4）；查看者無此入口 |
| 直播訂閱 | 訂閱房間、設定自動錄製與開播通知 |
| 網頁推送 | 通過 Service Worker 接收開播等 Web Push 通知 |
| 檔案瀏覽 | 瀏覽錄製檔案，支持下載與 MP4 內置回放；可顯示彈幕滾動與禮物特效 |
| 錄製信息 | 顯示實際畫質、實際流格式、彈幕檔案大小與標題變更提示 |
| 檔案共享 | 生成帶過期時間的分享鏈接（需公網可達的後端與 `PUBLIC_BASE_URL`；bilirec-mobile 本機部署通常不可用，見下文） |
| 格式轉換 | 提交與管理 FLV/TS/FMP4 → MP4 轉換任務 |
| 磁碟監測 | 實時磁碟佔用與分項統計 |
| 角色控制 | 管理員 / 查看者（查看者可瀏覽檔案與成片回放，不能開停錄、不能預覽錄製中內容） |
| 深色模式 | 淺色/深色主題，支持跟隨系統 |
| 多語言 | 簡體中文 / 繁體中文 |
| 多伺服器 | 登入頁可設定後端地址，連接不同 bilirec 實例 |
| PWA | 可安裝到桌面或手機主屏幕，獲得接近原生 App 的體驗 |

<Aside type="tip">
bilirec-web 需配合正在運行的 [bilirec](https://github.com/bilirec/bilirec) 後端使用。也可[自行部署前端](/zh-tw/development/web/)以連接局域網 HTTP 後端或使用自定義域名。
</Aside>

## 存取 Web 介面

1. 確保 bilirec 後端已啟動（預設端口為 `8080`，`HOST` 預設為空值即監聽所有網卡）
2. 打開 [app.bilirec.org](https://app.bilirec.org/)

</TabItem>

</Tabs>

3. 在登入介面填入後端地址（本地使用可留空或填 `http://localhost:8080`）
4. 若設定了 `USERNAME` 和 `PASSWORD`，輸入帳號密碼登入；未設定則直接進入

## B 站登入

進入主介面後，點擊右上角頭像（移動端為設定），在菜單中完成 B 站登入。

桌面端使用 Bilibili App 掃描二維碼。手機端打開登入窗口後，預設在「本機 App」頁籤：點擊「使用 B 站客戶端登入」，在 B 站 App 中確認後**手動切回本頁**；切回後頁面會自動完成登入。也可切換到「其他裝置掃碼」，用另一台已安裝 B 站客戶端的設備掃描。

## 錄製與回放

開始錄製時可以開啟「錄製彈幕」。房間自動錄製會沿用房間設定中的這項設定；具體設定見[錄製直播間](/zh-tw/guides/recording/)和[彈幕錄製](/zh-tw/configuration/danmaku/)。

### 錄製中預覽

在 **錄製管理** 中，**管理員** 對狀態為「錄製中」的任務可點綠色 **預覽錄製**，在全屏播放器裡看當前分段正在寫入的畫面（或純音頻佈局）。**只讀查看者** 登入時不會出現該按鈕，後端也不會接受其預覽請求。

可用條件簡要如下：

- 當前任務處於 **錄製中**（恢復中、空閒不顯示）
- 實際流格式為 **FLV、TS 或 fMP4**（與卡片上顯示的實際流格式一致）
- 使用 **管理員** 帳號；設定了 `VIEWER_USERNAME` / `VIEWER_PASSWORD` 的只讀帳號不能預覽

預覽走實時流，不是「錄製檔案」裡的 MP4/M4A。你會看到：

- 進度條為 **可回溯時段**（預設約 60 秒，可在播放設定的「錄製預覽回看緩衝」裡改為 15–120 秒）；拖到右側貼近直播沿時顯示 **LIVE**，落後時可點 **回到直播**
- 若本次錄製開啟了彈幕且輸出為 **`jsonl`**，彈幕、禮物、醒目留言與艦長等會隨直播推送；連接時會先補最近約一分鐘已寫入 sidecar 的互動。未開彈幕或僅有 `xml` 時只有畫面或純音頻介面
- **僅音頻** 錄製時顯示專用音頻介面，仍可預覽
- 流 **分段**（PK、斷流恢復等）結束時播放器會自動重連下一段；**停止錄製** 或當前不可預覽時窗口會關閉

<Aside type="note">
回看緩衝越大，瀏覽器佔用的記憶體越多。超過 90 秒時，1080p 直播在瀏覽器內可能佔用近百 MB 或更多；舊設備或多開預覽標籤頁時，可在播放設定裡把緩衝調低。修改緩衝後會重新連接預覽流。
</Aside>

<Aside type="note">
若使用 Nginx 等反向代理，請勿對 `/preview/` 路徑開啟響應緩衝，否則畫面可能卡頓或彈幕遲遲不出現。見 [伺服器與網路](/zh-tw/configuration/server-network/#nginx-反代示例)。
</Aside>

### 成片回放

在 **錄製檔案** 中選擇 MP4 或 M4A 的回放按鈕，會在當前介面打開內置播放器。播放器支持：

- 彈幕滾動、彈幕顯隱與透明度調整
- 禮物、醒目留言和艦長等互動特效
- 倍速、快進/快退與逐幀查看
- 畫面適應、裁切、拉伸，以及桌面和移動端全屏

播放器會盡量先載入同名彈幕檔案再開始播放。彈幕較多或網路較慢時，可能會先允許播放影片，彈幕與禮物特效就緒後再顯示。

播放設定裡的「防彈幕重疊」預設開啟。彈幕特別密時，畫面上可能比「已裝填」的條數更少，不等於檔案缺了記錄；對照方法見 [常見問題](/zh-tw/guides/faq/#開啟彈幕後回放裡的消息還是變少)。

## 檔案分享

在 **錄製檔案** 頁，對單個檔案可生成限時分享鏈接並複製到剪貼板。對方在有效期內打開鏈接即可下載，無需登入 bilirec。

使用此功能前請確認：

1. 你的 bilirec **能從互聯網存取**（公網伺服器、端口映射、[FRP](/zh-tw/guides/frp/) 等），而不只是 `localhost` 或局域網地址。
2. 已在環境中設定 **`PUBLIC_BASE_URL`**，且值為上述對外的完整 `http://` 或 `https://` 基址（見 [伺服器與網路](/zh-tw/configuration/server-network/)）。

<Aside type="note">
通過 [bilirec-mobile](/zh-tw/guides/android/) 在手機上跑後端時，API 預設僅本機可存取，App 也未提供 `PUBLIC_BASE_URL` 的常規設定項，**一般無法**向他人分享可用的下載鏈接。若要在手機上使用 Web 裡的分享功能，需自行完成公網暴露與 `PUBLIC_BASE_URL` 設定（進階用戶可在 App 開發者選項中添加環境變數）。更多說明見 [檔案管理 — 分享鏈接](/zh-tw/guides/file-management/#分享鏈接)。
</Aside>

## 連接自架後端

[app.bilirec.org](https://app.bilirec.org/) 通過 **HTTPS** 提供，而多數自架 bilirec 後端預設只提供 **HTTP**。多數瀏覽器會阻止 HTTPS 頁面直接請求 HTTP 的局域網地址（如 `http://192.168.x.x:8080`）；`http://localhost:8080` 和 `http://127.0.0.1:8080` 通常是例外：

- `http://localhost:8080`
- `http://127.0.0.1:8080`

| 後端位置 | 能否用 app.bilirec.org 連接 |
|---------|---------------------------|
| 本機（bilirec-mobile、PC 本機後端） | 可以，填 `localhost` 或 `127.0.0.1` |
| 局域網另一台設備上的 HTTP 後端 | 多數瀏覽器會阻止 HTTPS 前端直接連接 HTTP 局域網地址 |
| 公網 HTTPS（FRP、自架域名、反向代理等） | 可以，填 `https://你的後端地址`；需 `PRODUCTION_MODE=true`，見 [常見問題](/zh-tw/guides/faq/#用-appbilirecorg-連遠端後端一直提示會話過期)。官方頁連 `*.tunnel.bilirec.org` 同屬 `bilirec.org`，一般不必為登入允許第三方 Cookie |

遠端存取局域網內的 HTTP 後端，可考慮 [FRP](/zh-tw/guides/frp/) 等提供 **HTTPS** 的方案。自架 HTTPS 後端通過 app.bilirec.org 登入時，建議開啟生產模式。[自架前端](/zh-tw/development/web/)且與後端**根域名不同**時，可能還需允許第三方 Cookie，見 [FRP — 根域名是否相同](/zh-tw/guides/frp/#根域名是否相同)。

## 安裝 PWA

bilirec-web 支持 PWA（Progressive Web App），可安裝到桌面或手機主屏幕，獲得接近原生 App 的體驗。安裝後會記住上次連接的後端地址。

<Tabs>
<TabItem label="Android Chrome">

若瀏覽器檢測到可安裝，頁面頂部會出現安裝橫幅，點擊 **安裝** 即可：

<img src="/images/web-ui/pwa-install-banner.png" alt="Android Chrome PWA 安裝橫幅" width="400" style="max-width:100%;height:auto;display:block;margin:0 auto" />

也可通過菜單 **⋮**，選擇 **新增至主屏幕**（部分機型顯示為「安裝應用」）：

<img src="/images/web-ui/pwa-menu-add-home.png" alt="Chrome 菜單「新增至主屏幕」" width="400" style="max-width:100%;height:auto;display:block;margin:0 auto" />

在確認對話框中點擊 **安裝**：

<img src="/images/web-ui/pwa-install-dialog.png" alt="PWA 安裝確認對話框" width="400" style="max-width:100%;height:auto;display:block;margin:0 auto" />

</TabItem>
<TabItem label="桌面瀏覽器（Chrome / Edge）">

打開 [app.bilirec.org](https://app.bilirec.org/) 後，點擊地址欄右側的 **安裝** 圖標：

<img src="/images/web-ui/pwa-desktop-login.png" alt="桌面 Chrome 登入頁與地址欄安裝按鈕" style="max-width:100%;height:auto;display:block;margin:0 auto" />

在「安裝應用程式」對話框中點擊 **安裝**：

<img src="/images/web-ui/pwa-desktop-install-dialog.png" alt="桌面 Chrome PWA 安裝確認對話框" style="max-width:100%;height:auto;display:block;margin:0 auto" />

若地址欄沒有安裝圖標，可打開菜單 **⋮**，選擇 **安裝 Bilibili 錄製管理**（或「安裝 bilirec」）。

</TabItem>
<TabItem label="iOS Safari">

點 **分享**，再選 **添加到主屏幕**。

</TabItem>
</Tabs>
