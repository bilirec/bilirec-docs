本頁按**目標**串起步驟：成片留在你的機器上，訪客通過 Web **帶彈幕回放**或下載。需要設定管理員與只讀帳號，並把 API 安全地暴露到公網。

<Aside type="tip">

本站計劃免費提供用 Bilirec 搭建、**面向粉絲公開**的錄播站（可長期使用，單站約 **100 GB** 儲存）。有興趣者可加入 [Q群](https://qm.qq.com/q/oMTN3EsGBy) 諮詢，或 [填寫申請表](https://forms.cloud.microsoft/r/Uj04eD73SG)。

</Aside>

## 適合誰

- 想給粉絲或朋友提供**在線看錄播 / 下檔案**，而不是只自己看
- 願意設定**管理員 + 只讀訪客**帳號，並在公網暴露 API 時設密碼

其他場景指南：[自用錄像庫](/zh-tw/guides/personal-archive/)、[全自動掛機上傳](/zh-tw/guides/auto-upload/)。

## 前端

訪客用的網頁和錄播程式是分開的。可以直接打開官方頁 [app.bilirec.org](https://app.bilirec.org/)，也可以把同一套網頁部署到自己的域名，做法見 [自行部署（Cloudflare）](/zh-tw/development/web/#自行部署cloudflare)。

自架之後，每臺後端的 `FRONTEND_URL` 填這個網頁的 HTTPS 地址，並建議 `PRODUCTION_MODE=true`。繼續用官方頁時，`FRONTEND_URL` 仍是 `https://app.bilirec.org`。根域名與後端不同時，見 [生產模式](/zh-tw/configuration/auth-security/#何時需要生產模式) 與 [FRP — 根域名是否相同](/zh-tw/guides/frp/#根域名是否相同)。

前後端分開，所以可以同時跑多臺 bilirec。粉絲用同一套網頁（官方或自架），在登入頁改「伺服器地址」就能換到另一台，不必為每臺再部署一個網頁。每臺仍要單獨暴露到公網，並各自設定管理員帳號、只讀帳號和 `FRONTEND_URL`。

<Aside type="note">

**半公開：** 對方要知道錄播伺服器地址，並且輸入只讀帳號密碼，才能瀏覽、回放和下載。做不到完全公開：不能變成打開一個網址就能翻庫，既不用帳號，也不用另填伺服器地址。

</Aside>

## 步驟清單

<Steps>

1. [安裝](/zh-tw/guides/installation/)並[啟動](/zh-tw/guides/quick-start/) bilirec，完成 B 站登入。
2. 設定**管理員** `USERNAME` / `PASSWORD`；公網暴露後未設定時 API 完全公開，見 [認證與安全](/zh-tw/configuration/auth-security/)。
3. 設定**只讀訪客** `VIEWER_USERNAME` / `VIEWER_PASSWORD`：訪客可瀏覽、回放、下載，不能改訂閱或開停錄。
4. 在 Web「訂閱管理」為房間開啟**自動錄製**，見 [錄製直播間](/zh-tw/guides/recording/)。
5. 保持 **`DANMAKU_OUTPUT_FORMAT=jsonl`**，與 bilirec-web 彈幕回放配套，見 [彈幕錄製](/zh-tw/configuration/danmaku/) 與 [Web 介面 · 錄製與回放](/zh-tw/guides/web-ui/#錄製與回放)。
6. 開啟 **`CONVERT_TO_MP4=true`**，錄製結束後生成 MP4，訪客才能在瀏覽器裡穩定回放，見 [轉換設定](/zh-tw/configuration/conversion/)。
7. 按需調整 `MIN_DISK_SPACE_BYTES`；某房間可在訂閱裡開啟「空間不足時刪除最舊檔案」，見 [錄製設定 · 磁碟空間](/zh-tw/configuration/recording/#磁碟空間)。
8. 設定 **`PUBLIC_BASE_URL`** 為訪客實際存取後端的 HTTPS 基址（含 `https://`），用於分享與預簽名下載，見 [伺服器與網路](/zh-tw/configuration/server-network/) 與 [檔案管理 · 分享鏈接](/zh-tw/guides/file-management/#分享鏈接)。
9. 用 [FRP](/zh-tw/guides/frp/) 或自建反代把服務暴露到公網；訪客可用 [app.bilirec.org](https://app.bilirec.org/) 或[自架網頁](/zh-tw/development/web/#自行部署cloudflare)登入，將後端的 `FRONTEND_URL` 設為實際使用的網頁 HTTPS 地址（官方頁為 `https://app.bilirec.org`），並建議 `PRODUCTION_MODE=true`，見 [認證與安全 · 生產模式](/zh-tw/configuration/auth-security/#何時需要生產模式)。

</Steps>

<Aside type="caution">

- 公網暴露後務必設定管理員密碼。
- 只讀帳號不能防止分享鏈接被轉發。
- 預簽名分享可設有效期（預設 1 小時，可改 `ttl`），見 [檔案管理 · 分享鏈接](/zh-tw/guides/file-management/#分享鏈接)。

</Aside>

## 設定示例

以下片段可合併進 `.env`（路徑、密碼請自行替換）：

```bash
OUTPUT_DIR=/path/to/records

USERNAME=admin
PASSWORD=請改為強密碼
VIEWER_USERNAME=guest
VIEWER_PASSWORD=請改為強密碼
JWT_SECRET=請改為隨機長字符串

DANMAKU_OUTPUT_FORMAT=jsonl
CONVERT_TO_MP4=true

MIN_DISK_SPACE_BYTES=5368709120

PRODUCTION_MODE=true
FRONTEND_URL=https://app.bilirec.org  # 自架網頁時改為你的前端 HTTPS 地址
PUBLIC_BASE_URL=https://你的公網後端地址

# FRP_ENABLED=true 等見遠端存取（FRP）；不用官方 FRP 時可不設並自建反代
# TRUSTED_PROXIES=反代或 FRP 出口 IP，逗號分隔；見伺服器與網路
# delete_oldest_on_low_disk 在 Web 訂閱或房間 API 按房間設定，見錄製設定 · 磁碟空間
```

## 錄完檔案在哪？

成片在 **`OUTPUT_DIR`**（預設 `records`）下的 `{主播名}-{房間號}/`；訪客在 Web 裡看到的即此目錄。瀏覽、分享與在線回放見 [檔案管理](/zh-tw/guides/file-management/)。
