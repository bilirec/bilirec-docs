---
title: 用 AI 查文檔
description: 用站內問文檔、自己的 AI，或文檔全文來查找設定與排錯說明
---

查設定或排錯時，除了翻目錄和 [常見問題](/zh-tw/guides/faq/)，還可以讓 AI 按本站文檔查找。三種方式可以一起用：人還在網頁上時用右下角提問；已經在用自己的 AI 時把文檔接進去；額度用完或不想設定時，把文檔全文交給任意聊天工具。

AI 的回答方便縮小範圍。改設定或處理故障時，仍建議對照原文和日誌。

## 站內問文檔

本站任意頁面右下角有「問文檔」。用白話描述你看到的現象即可，例如啟動報錯、回放彈幕變少。回答依據本站文檔，每天有使用額度。額度用盡或暫時繁忙時，可改用下面兩種方式。

## 接到自己的 AI

如果你已經在用支持 MCP（一種讓 AI 讀取外部資料的接入方式）的工具，把文檔加進去後，就可以直接問安裝、設定和排錯問題，不必自己複製網頁。

地址：

```
https://llm.bilirec.org/mcp
```

在工具的 MCP 或遠端伺服器設定裡填入上述地址。各家介面不同，以工具自己的說明為準。設定檔案常見寫法：

```json
{
  "mcpServers": {
    "bilirec-docs": {
      "url": "https://llm.bilirec.org/mcp"
    }
  }
}
```

## 把文檔全文交給 AI

不想設定 MCP 時，可以把下面的網址發給任意聊天工具，讓它先讀再回答。這不佔用站內「問文檔」的額度。

| 檔案 | 適合 |
|------|------|
| [`llms.txt`](https://www.bilirec.org/llms.txt) | 只要目錄和摘要 |
| [`llms-small.txt`](https://www.bilirec.org/llms-small.txt) | 比目錄多一些、比全文短 |
| [`llms-full.txt`](https://www.bilirec.org/llms-full.txt) | 需要細查設定時用完整正文 |

內容和網頁上的文檔相同。若剛更新過說明，請以網頁為準。

## 怎麼選

| 你現在的情況 | 更合適的方式 |
|--------------|--------------|
| 正在看文檔，只想隨口問一句 | 右下角「問文檔」 |
| 已經在用自己的 AI，希望它能查本站說明 | 填入上面的地址 |
| 任意聊天工具，或不想額外設定 | 把 `llms.txt` 或 `llms-full.txt` 的網址交給它 |

仍建議先看 [常見問題](/zh-tw/guides/faq/) 是否已有對應條目，再用 AI 縮小範圍，最後回到具體設定頁確認預設值和注意事項。
