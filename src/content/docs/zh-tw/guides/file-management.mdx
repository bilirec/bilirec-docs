bilirec 將錄製檔案保存在 `OUTPUT_DIR`（預設 `records`）目錄下，可通過 Web 介面或 REST API 管理。

## 瀏覽檔案

在 Web 介面的檔案管理頁面瀏覽錄製目錄，支持按檔案名搜索與分頁。錄製彈幕後，與影片同名的彈幕檔案也會顯示在檔案列表中。

API：

```bash
curl "http://127.0.0.1:8080/files/browse/?offset=0&limit=50&search=title"
```

## 彈幕檔案

開啟彈幕錄製後，每個影片檔案旁邊可能會有同名的 `.jsonl` 或 `.xml` 檔案。它們保存普通彈幕、醒目留言、禮物和艦長等互動記錄，不是影片檔案，不能直接用影片播放器打開。

使用 bilirec-web 回放時，宜選 `.jsonl`，播放器方能還原滾動彈幕與禮物特效。`.xml` 則按 [彈幕 XML 的後續使用](/zh-tw/guides/danmaku-xml/) 接入錄播姬生態裡的 XML 工具；Web 播放器不為 XML 疊這些效果。

## 下載檔案

```bash
curl -O "http://127.0.0.1:8080/files/download/room123/title.flv"
```

## 在線回放

已轉換為 MP4 的檔案可以在 Web 介面的內置播放器中回放，也可以通過 API 直接獲取影片流：

```bash
curl "http://127.0.0.1:8080/files/playback/username-roomID/20250101.mp4"
```

## 預簽名下載

需要認證，創建臨時下載鏈接：

```bash
curl -X POST "http://127.0.0.1:8080/files/presigned/room123/title.mp4?ttl=3600" \
  -b cookies.txt
```

## 分享鏈接

在 [Web 管理介面](/zh-tw/guides/web-ui/) 的錄製檔案列表中，可為單個檔案生成帶有效期的分享鏈接（複製到剪貼板後發給他人）。接口與上文的預簽名下載相同：對方在有效期內存取鏈接即可下載，無需登入。

<Aside type="note">
**需要對外可存取的後端。** 他人打開鏈接時會向你的 bilirec 後端發起下載請求。若服務只在本機或局域網內、未做內網穿透或反向代理，公網上的用戶無法拉取檔案。請先將 API 暴露到外網（例如 [FRP](/zh-tw/guides/frp/)），再設定可從公網存取的完整基址 `PUBLIC_BASE_URL`（見 [伺服器與網路](/zh-tw/configuration/server-network/)）。`PUBLIC_BASE_URL` 為空或無效時，後端會回退為相對路徑，對方拿到的鏈接通常無法直接使用。

**bilirec-mobile 場景。** 原生 App 沒有單獨的「分享」入口，須在「打開錄製管理程式」進入 Web/PWA 後操作。手機常見部署下後端僅監聽本機 `127.0.0.1`，且 App 設定頁未提供 `PUBLIC_BASE_URL` 開關，一般**無法**向他人提供可用的外鏈；若確有需要，需自行解決公網可達性，並在開發者選項的環境變數中設定 `PUBLIC_BASE_URL`。
</Aside>

## 批量刪除

```bash
curl -X DELETE http://127.0.0.1:8080/files/batch \
  -H "Content-Type: application/json" \
  -d '["room123/20250101.flv","room456/20250102.flv"]'
```

## 媒體轉換

啟用 `CONVERT_TO_MP4=true` 後，錄製完成的 FLV/TS/fMP4 檔案會自動加入轉換隊列。大檔案（≥ `CLOUDCONVERT_THRESHOLD`，預設 1 GB）優先使用 CloudConvert 雲端轉換。

轉換任務狀態查詢見 [轉換任務 API](/zh-tw/api/convert/)，設定見 [轉換設定](/zh-tw/configuration/conversion/)。

完整 API 參考見 [檔案管理 API](/zh-tw/api/files/)。
