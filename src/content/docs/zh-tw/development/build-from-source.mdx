## 開發模式

```bash
make dev    # go run ./cmd/backend
```

## 建置二進制

`os` 為空時預設 Windows。桌面後端交叉編譯不使用 CGO。

```bash
make build                 # 輸出 ./dist/bilirec-windows.exe（預設）
make build os=windows      # 同上
make build os=linux        # ./dist/bilirec-linux-amd64 與 ./dist/bilirec-linux-arm64
make build os=darwin       # ./dist/bilirec-darwin-arm64 與 ./dist/bilirec-darwin-amd64
make build os=android      # Android .so，按本機自動選擇 NDK prebuilt
```

也可直接交叉編譯單個架構：

```bash
CGO_ENABLED=0 GOOS=darwin GOARCH=arm64 go build -o ./dist/bilirec-darwin-arm64 ./cmd/backend
CGO_ENABLED=0 GOOS=darwin GOARCH=amd64 go build -o ./dist/bilirec-darwin-amd64 ./cmd/backend
```

支持平台：Linux amd64/arm64、macOS amd64/arm64、Windows、Android (.so)。

## Android 庫

需要 Android NDK 24+ 及 `./lib/<abi>/libffmpegkit.so`。推薦：

```bash
make build os=android
```

也可顯式指定 NDK 主機（本機操作系統），而不是編譯目標：

```bash
# Linux 主機
make android os=linux

# Windows 主機
make android os=windows

# macOS 主機
make android os=darwin
```

`NDK_HOME` 從 `ANDROID_NDK_LATEST_HOME`、`ANDROID_NDK_ROOT` 或 `ANDROID_NDK_HOME` 中選取。

輸出：`dist/android/<abi>/libbilirec.so`（預設 `arm64-v8a` 與 `x86_64`）。

## 要求

- Go 1.26+
- FFmpeg + ffprobe（可選，本地 MP4 轉換）
- Android NDK r24+（Android 建置）

預編譯二進制見 [GitHub Releases](https://github.com/bilirec/bilirec/releases)。
