## 瀏覽檔案

```http
GET /files/browse/*
```

| 參數 | 說明 | 預設值 |
| ---- | ---- | ------ |
| `offset` | 分頁偏移量 | `0` |
| `limit` | 每頁最大條數（0=不限制，最大 200） | `0` |
| `search` | 按檔案名搜索（大小寫不敏感） | (不過濾) |

```json
{
  "total": 42,
  "items": [
    { "name": "title.flv", "is_dir": false, "path": "room123/title.flv", "size": 1048576 }
  ]
}
```

## 下載檔案

```http
GET /files/download/{path}?presigned={token}
```

需要攜帶有效的預簽名 token（見下方「預簽名下載」，`purpose` 使用 `download` 或省略）。token 與請求路徑綁定，路徑不符返回 `403`，過期返回 `403`，缺失返回 `401`。

直接返回儲存的檔案。

若要將源檔案（FLV/TS/fMP4）自動轉為 MP4 或 M4A，可啟用 `CONVERT_TO_MP4`。錄製結束後可轉換檔案會被加入轉換隊列：

- 同時設定 `CLOUDCONVERT_API_KEY` 且檔案大小 `>= CLOUDCONVERT_THRESHOLD`（預設 1 GB）時，優先走 CloudConvert
- 否則走本地 FFmpeg 後台任務
- 轉換任務可通過 `GET /convert/tasks` 查詢

## 預簽名下載

```http
POST /files/presigned/{path}?ttl=<seconds>&purpose=<purpose>
```

需要 JWT 認證。`ttl` 預設 3600 秒。`purpose` 決定返回的 URL 指向哪條路由：

- `download`（預設）：返回 `/files/download/{path}?presigned=<token>`，以附件形式下載
- `playback`：返回 `/files/playback/{path}?presigned=<token>`，用於瀏覽器內聯播放
- `share`：返回同 `download`，但每次都簽發全新鏈接，適合分享場景

`download` 與 `playback` 會複用 URL：同一檔案、同一用途在到期前重複請求時，返回同一條 URL，便於 CDN 按穩定網址緩存；此時 `expires_in` 是該 URL 的剩餘有效秒數。剩餘不足 5 分鐘時才會重新簽發新 URL。`share` 則不受影響，總是返回新鏈接。

返回的 URL 無需 cookie 即可存取，適合交給 CDN、外部播放器或下載工具重放。token 與檔案路徑綁定並帶過期時間，過期後失效；正在錄製的檔案無法生成。

## 批量刪除

```http
DELETE /files/batch
Content-Type: application/json

["room123/20250101.flv", "room456/20250102.flv"]
```

## 刪除目錄

```http
DELETE /files/{path}
```

## 在線播放

```http
GET /files/playback/{path}?presigned={token}
```

需要攜帶有效的預簽名 token（`purpose` 使用 `playback`）。返回 MP4 或 M4A 媒體流，瀏覽器可直接播放。支持 Range 請求（快進/快退）。

- 支持 MP4 與 M4A
- 無法播放進行中的錄製檔案（正在寫入的分段請用 [錄製中預覽](/zh-tw/api/preview/)，僅管理員）
- token 過期後返回 `403`，播放器應在過期前重新調用預簽名接口換取新 URL

```html
<video controls width="100%">
  <source src="/files/playback/username-roomID/20250101.mp4" type="video/mp4">
</video>
```

## 獲取影片對應的彈幕檔案

```http
GET /files/danmaku/{path}
```

`path` 傳入影片檔案路徑，服務會查找與影片同名的彈幕檔案，並優先返回 `.jsonl`，找不到時再嘗試 `.xml`：

```bash
curl "http://127.0.0.1:8080/files/danmaku/username-roomID/20250101.mp4"
```

返回內容類型為 `application/x-ndjson` 或 `application/xml`。當前影片分段仍在錄製時返回 `400`；沒有對應彈幕檔案時返回 `404`。
