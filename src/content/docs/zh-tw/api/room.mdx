## 獲取房間信息

```http
GET /room/:roomID/info
```

```json
{
  "room_id": 123,
  "short_id": 456,
  "title": "房間標題",
  "description": "房間描述",
  "live_status": 1,
  "followers": 10000,
  "cover": "https://example.com/cover.jpg"
}
```

- `200`：成功
- `400`：無效房間 ID
- `404`：房間不存在
- `500`：伺服器內部錯誤

## 解析房間 ID

短房間號和真實房間號都可以傳入此接口。返回值會同時給出本次查詢使用的 ID、真實 `room_id` 與 `short_id`：

```http
GET /room/:roomID/resolve
```

```json
{
  "query_id": 456,
  "room_id": 123,
  "short_id": 456
}
```

- `200`：解析成功
- `400`：無效房間 ID
- `404`：房間不存在

## 批量獲取房間信息

```http
POST /room/infos
Content-Type: application/json

{ "roomIDs": [123, 456, 789] }
```

支持 query：`?roomIDs=123,456,789` 或 JSON `{"roomIDs":[...]}`（也接受 `room_ids`、`roomIds`）。

```json
{
  "123": { "room_id": 123, "title": "標題1" },
  "456": { "room_id": 456, "title": "標題2" }
}
```

## 檢查直播狀態

```http
GET /room/:roomID/live
```

```json
{ "room_id": 123, "is_live": true }
```

- `200`：成功
- `400`：無效房間 ID
- `404`：房間不存在
- `500`：伺服器內部錯誤

## 批量檢查直播狀態

```http
POST /room/lives
```

支持 query 或 JSON payload，響應：`{"123": true, "456": false}`

```json
{
  "123": true,
  "456": false,
  "789": true
}
```

## 訂閱管理

| 方法 | 路徑 | 說明 |
|------|------|------|
| `POST` | `/room/:roomID` | 訂閱房間（`200` 成功，`409` 已訂閱） |
| `DELETE` | `/room/:roomID` | 取消訂閱 |
| `GET` | `/room/subscribe/:roomID` | 檢查訂閱狀態 |
| `GET` | `/room/subscribe` | 列出所有訂閱（`{"room_ids": [123, 456]}`） |

## 房間設定

**獲取：**

```http
GET /room/:roomID/config
```

```json
{
  "room_id": 123,
  "auto_record": true,
  "notify": true,
  "record_duration_minutes": 120,
  "qn": 150,
  "only_audio": false,
  "record_danmaku": true,
  "stream_profiles": ["hls-fmp4", "hls-ts"],
  "delete_oldest_on_low_disk": false
}
```

**更新：**

```http
PUT /room/:roomID/config
Content-Type: application/json

{
  "auto_record": true,
  "notify": true,
  "record_duration_minutes": 120,
  "qn": 150,
  "only_audio": false,
  "record_danmaku": true,
  "stream_profiles": ["hls-fmp4", "hls-ts"],
  "delete_oldest_on_low_disk": false
}
```

`auto_record`、`notify` 為行為開關，不參與開錄參數。啟用自動錄製後，下列字段會在開錄時**全部**生效（與 [錄製管理 API](/zh-tw/api/record/) 中同名 query 參數同義）：

- `record_duration_minutes`：`0` 系統預設，`-1` 不限時，正整數為 N 分鐘（**僅**自動錄製讀取；手動開錄用請求 query `duration_minutes`）
- `qn`、`only_audio`、`record_danmaku`
- `stream_profiles`：空或省略=允許全部格式；數組為嚴格允許清單，元素為 `http-flv` / `hls-ts` / `hls-fmp4`
- `delete_oldest_on_low_disk`：預設 `false`；為 `true` 時，可用空間低於 `MIN_DISK_SPACE_BYTES` 會先刪除該房間檔案名時間戳最早的錄像再嘗試啟動
